# MediCare - Clinic Management System

A robust and comprehensive web-based Clinic Management System designed to streamline patient records, medical history tracking,
and appointment workflows efficiently. Built using modern backend and web development technologies.
---

## Key Features

* **Patient Records Management:** Create, update, and manage comprehensive patient profiles and medical histories securely.
* **Appointment Tracking:** Seamlessly schedule, track, and manage doctor consultations and daily appointments.
* **Secure Authentication:** Built-in security and role-based access control utilizing ASP.NET Core Identity.
* **Clean Architecture:** Developed following best software engineering practices, ensuring high maintainability and scalability.

---

## Tech Stack

* **Backend & Logic:** C#, ASP.NET Core MVC, Entity Framework Core
* **Database:** Microsoft SQL Server
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
